# 用户名与密码模式

- 只填写用户名和密码。用户名为3–24个汉字、英文字母、数字、下划线或短横线；英文字母大小写视作相同用户名，注册后固定。
- 用户名经 NFKC 规范化和 SHA-256 确定性映射为内部认证标识。accounts.invalid 为保留、不可投递域名，不代表玩家邮箱。密码仍由 Supabase Auth 处理，前端不保存明文密码。
- 使用原生 signUp / signInWithPassword，保留认证限流。无需新增管理员密钥或自建密码数据库。
- 正式启用前，需要关闭项目 Authentication 的 Confirm email。否则内部标识不能完成邮件确认，也无法正常注册。项目邮箱确认设置已关闭并保存，正在发布用户名密码版。
- 暂不支持邮箱找回密码。已登录玩家可验证当前密码后修改密码。没有身份恢复渠道时，忘记密码不能自助恢复。
- 云存档仍根据认证用户 UUID 隔离，用户名或 user_metadata 不作为存档访问权限依据。
- 现有邮箱账号及存档未删除、未自动转换；旧邮箱用户重新注册用户名会产生不同账号。需要迁移时另行处理。
- 构建与模拟 SDK 测试不能代替真实注册、登录、云存档及跨设备验收。

官方配置参考：https://supabase.com/docs/reference/javascript/auth-signup
