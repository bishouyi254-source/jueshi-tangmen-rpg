# 绝世唐门 RPG · 本地复刻

静态浏览器游戏，GitHub Pages 发布目录。包含本地版本的魂环修复、自定义武魂和轮回之影更新。

## 发布

GitHub Pages：Deploy from a branch → main → / (root)。根目录的 .nojekyll 禁用 Jekyll。

## 存档和路由

角色保存在当前浏览器的 localStorage，不含服务器或数据库。不同域名的存档相互独立；仓库不包含个人存档。刷新游戏路由会回到标题页，通过继续游戏恢复角色，这是本地版本的启动兼容方式。

部分背景图片依赖第三方 CDN，其可用性不由本仓库保证。

## 来源

基于用户提供的本地复刻构建及其修改。原始游戏及第三方依赖的权利归各自权利人；此仓库未添加重新授权许可。
