# 斗罗复刻版控制台 1.0.4

新增凶兽机制适配：沉默或魂力不足、没有可用数字技能时，自动回退普通攻击，避免卡在等待下一回合。重载此独立扩展后生效。

这是独立的 Chrome 扩展，使用工作区现有控制台代码适配复刻入口。不会替换你当前已安装的 1.4.25 控制台。原版只显示存档导出工具，自动任务控制台只在复刻版启用。

## 复制原版存档到复刻版

1. 安装或重载此扩展（已有安装请点击扩展卡片上的“重新加载”），然后刷新原版与复刻版页面。
2. 在原版停止自动任务并结束战斗，展开左下角“存档复制工具”，点击“导出存档副本”。Chrome 会下载 JSON 文件，原版角色保留不动。
3. 在复刻版停止自动任务并结束战斗，展开“斗罗复刻版控制台”面板底部的“存档复制工具”，点击“导入存档副本”，选择刚下载的原版文件。
4. 确认覆盖复刻版当前存档。导入前会先在复刻版浏览器本地存储保留旧存档，并发起旧存档备份下载；留意 Chrome 下载列表或下载拦截提示。旧存档备份失败时不会调用导入。
5. 页面提示导入成功后核对名字、等级、武魂、装备，然后刷新确认保存。两边进度各自保存，不自动同步。

工具没有网络传输，使用游戏已有导出与导入函数。原版不提供导入按钮。也支持已有的存档码 TXT 文件或角色 JSON 文件；旧格式兼容能力取决于游戏自身导入函数。

模拟测试覆盖导出下载、取消导入、覆盖前的下载与本地备份、原版不变、战斗及无效文件拦截。已验证原版真实角色导出；原导出接口返回空时，使用当前已加载角色的完整 JSON 作为副本。尚未将用户存档导入复刻版。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”（部分版本显示“加载未打包的扩展程序”）。
4. 选择本文件夹：`C:\Users\ziho\Documents\Codex\2026-09-19\new-chat\outputs\斗罗复刻版控制台`。
5. 打开 `https://bishouyi254-source.github.io/jueshi-tangmen-rpg/`，刷新页面，进入或继续游戏。
6. 进入角色界面后会显示“斗罗复刻版控制台”，再手动开启任务。首页不显示控制台，也不会自动运行任务。

本机服务器端口为 4173 时也支持 `localhost` 和 `127.0.0.1`，兼容 `/app/app_17dnukzxw22/game` 和 `/game` 游戏路由。需先启动本地网站服务器。

## 更新与停止

更新该文件夹后，在扩展页重载“斗罗复刻版控制台”，再刷新游戏。原版扩展可以继续保留。

关闭任务会在操作检查点停止；刷新或关闭游戏页面也会结束当前任务。使用自动操作期间避免同时手动控制游戏。

验证范围：入口限制、面板注入与按钮启用；没有对每项自动挑战或一键轮回完整实测。
